# PageHeader

Thanh header mọi trang: cao 40px, lề 6px/24px, viền dưới 1px; tên app, vạch đứng đỏ, tên trang hiện tại.

- Lớp: `dq-header`; `dq-header-app` (22px đậm 700, tracking âm), `dq-header-bar` (vạch 2×20px màu `primary` — thay cho vạch cam orange-500 của Taskory), `dq-header-page` (19px font-light màu muted), `dq-header-actions` bên phải.
- Tên trang lấy đúng nhãn mục sidebar đang active — đổi nhãn sidebar là header đổi theo.
- Nút trong header dùng cỡ xs; nút `primary` ở header được tính là nút chính duy nhất của màn hình.
- "DQHPC Workspace" là tên tạm — thay bằng tên ứng dụng thật.
