# Sidebar

Điều hướng chính: rộng 248px, nền `sidebar`, viền phải 1px; thu gọn 48px (chỉ icon), mobile thành sheet 260px.

- Lớp: `dq-sidebar`; khối thương hiệu `dq-brand` (tên + eyebrow 10px tracking +0.14em); mục `dq-nav` cao 32px, icon 16px màu muted; nhóm `dq-nav-group`.
- Hover: nền `accent`.
- **Đang chọn** (`is-active`): nền `primary-soft`, chữ + icon `primary-text`, đậm 600, vạch trái 2px `primary`. Đây là một trong bốn chỗ được dùng đỏ.
- Mục dự án dẫn đầu bằng `dq-dot` trạng thái, không bằng màu thương hiệu.
- Chờ file logo DQHPC để thay khối chữ ở `dq-brand`.
