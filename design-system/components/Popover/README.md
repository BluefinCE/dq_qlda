# Popover

Lớp nổi cho dropdown, menu ngữ cảnh, dialog: nền `popover`, viền 1px, bo `radius-md`, `shadow-overlay` — tầng duy nhất của hệ được có bóng.

- Lớp: `dq-popover`; mục `dq-menu-item` cao 32px bo `radius-sm`, hover `accent`; phân cách `dq-menu-sep`.
- Mục phá huỷ (`dq-menu-danger`) dùng chữ `destructive`, đặt cuối, sau vạch phân cách, nhãn kết thúc bằng "…" vì sẽ mở hộp xác nhận.
